> ⚠ **시간 제약 안내**: 과제 제출 시간이 부족해 전체 학습을 **45 에폭 → 8 에폭(시드 1개), 5-fold는 3 에폭**으로 줄여 실행했다. 아래 모든 수치는 이 축소 설정의 실제 결과이며, 논문/강의 기준(45 에폭)보다 낮게 나오는 것이 당연하다. 분석에서 이 점을 함께 설명한다.

## 1. 코드 설명

### 사용한 데이터 및 전처리 방법
- 데이터: 논문 공개 데이터 (5명 × 50시행, 2채널, 1,000 Hz, 시행당 3초 = 3000×2). 출처: https://github.com/sea3551/palm-sEMG-doorknob-filtered (CC BY 4.0). 폴더명 A~E를 클래스 라벨로 사용한다.
- 공개 데이터는 이미 60 Hz 노치 + 20~500 Hz 대역통과가 적용된 상태이다. 본 코드는 60 Hz 노치(Q=30) → 20~499 Hz 4차 Butterworth 대역통과를 `filtfilt`로 **다시 적용**한다(이중 필터링, 500 Hz는 나이퀴스트 한계와 같아 499 Hz 사용).
- 분할: **시행(파일) 단위로 먼저 8:2 계층 분할**(학습 200시행 / 테스트 50시행, 겹침 0, 시드 42)한 뒤, 각 집합 안에서 윈도우를 생성한다 (데이터 누수 방지). 학습 3,800윈도우 / 테스트 950윈도우(클래스당 190).
- 윈도우 300 ms, 50% 오버랩 (시행당 19개) → 윈도우 단위 min–max 정규화(두 채널을 합쳐서 정규화하므로 진폭이 작은 Ch2는 상대적으로 눌린다) → CWT(스케일 1~32, Morlet `morl`, 절댓값) → 입력 텐서 3×32×300 (채널 1, 채널 2, 두 채널의 평균을 3채널로 사용). CWT 변환에 약 26초 소요.

### 사용한 AI/ML 모델
| 모델 | 설명 |
|---|---|
| DenseNet161 | 제안 모델. torchvision DenseNet161, 분류층을 5클래스로 교체, 사전학습 없음 (26,483,045 파라미터) |
| 2D CNN | 베이스라인 A. Conv(3→32)-Pool-Conv(32→64)-GAP-Linear 구조의 초경량 모델 (19,717 파라미터). 논문의 2D-CNN과는 다른(훨씬 작은) 모델이다 |
| ResNet18 | 베이스라인 B. torchvision ResNet18, `fc`를 5클래스로 교체, 사전학습 없음 (11,179,077 파라미터) |

### 학습 및 테스트 방법
- 공통 조건: 같은 분할, Adam, 학습률 0.001, 배치 16, **8 에폭(시간 제약, 원래 45)**, Cross-Entropy, 사전학습 없음, Dropout 미적용(논문은 Dropout 사용, 비율은 공개되지 않음).
- 시드 1개(42)로만 실행했다(원 계획은 3개 평균).
- 마지막 에폭의 모델로 테스트셋을 평가한다.
- 5-fold 교차검증은 DenseNet161만, 시행 단위 StratifiedKFold, 폴드마다 새 모델, **3 에폭(시간 제약, 원래 45)**으로 실행했다.
- 추론 시간은 테스트셋 샘플 1개를 예열 10회 후 100회 반복 측정한 평균이다.

### 코드 실행 방법
```bash
pip install -r requirements.txt
git clone --depth 1 https://github.com/sea3551/palm-sEMG-doorknob-filtered.git
# 전체 재현 (45 에폭, 시드 3개, 5-fold 45 에폭) — 시간 여유가 있을 때
python main.py --data-dir palm-sEMG-doorknob-filtered/data --epochs 45 --seeds 42 43 44 --cv
# 본 제출에 사용한 축소 실행 (시간 제약)
python main.py --epochs 8 --seeds 42 --cv --cv-epochs 3
```
결과는 `results/` 폴더에 저장된다.
환경: Google Colab GPU (`torch.cuda.is_available()` True로 확인)

## 2. 모델 성능 비교

| Model | Accuracy | Precision | Recall | F1-score |
|---|---|---|---|---|
| **DenseNet161** | **87.58** | **88.23** | **87.58** | **87.49** |
| 2D CNN | 60.84 | 60.90 | 60.84 | 59.82 |
| ResNet18 | 79.37 | 83.71 | 79.37 | 79.96 |

(Precision/Recall/F1은 macro 평균, 8 에폭·시드 1개 기준)

### 추가 지표
| Model | 학습 시간(초) | 파라미터 수 | 추론 시간(ms/샘플) | 최대 오류 쌍 |
|---|---|---|---|---|
| DenseNet161 | 247 | 26,483,045 | 22.74 | D→C (25건) |
| 2D CNN | 56 | 19,717 | 0.24 | B→E (85건) |
| ResNet18 | 55 | 11,179,077 | 2.23 | B→E (52건) |

### 5-fold 교차검증 (DenseNet161, 3 에폭)
| Fold | 1 | 2 | 3 | 4 | 5 | 평균 ± 표준편차 |
|---|---|---|---|---|---|---|
| Accuracy (%) | 67.68 | 72.63 | 77.16 | 73.05 | 74.11 | **72.93 ± 3.06** (ddof=0) / ± 3.42 (ddof=1) |

### 성능 분석
DenseNet161(F1 87.49%)이 세 모델 중 가장 우수했고, ResNet18(79.96%)이 다음, 2D CNN(59.82%)이 가장 낮았다. 파라미터 수 순서(DenseNet161 2,648만 > ResNet18 1,118만 > 2D CNN 2만)와 성능 순서가 그대로 일치한다. 2D CNN은 합성곱 2층짜리 초경량 구조라 300×32 크기의 미세한 CWT 패턴을 충분히 담지 못한 것으로 보이며, 특히 B 클래스 recall이 29.5%로 크게 낮아 B의 대부분(85건)을 E로 잘못 예측했다. ResNet18은 잔차 연결 덕분에 2D CNN보다 훨씬 안정적이지만, E의 recall은 96.8%로 매우 높은 반면 정밀도는 58.0%에 그쳐 다른 클래스(특히 B 52건, C 31건, A 27건)를 E로 과도하게 끌어당기는 경향을 보였다. 반면 DenseNet161은 모든 클래스의 recall이 72.1~97.4% 범위로 비교적 고르게 분포해, 밀집 연결 구조가 특정 클래스로의 쏠림을 줄이는 데 유리했다는 논문의 주장과 같은 방향의 결과를 보였다. 다만 세 모델 모두 8 에폭만 학습했고 DenseNet161의 손실 곡선이 아직 진동하는 중이라(7에폭에서 72.00%로 일시 하락), 더 많은 에폭을 학습하면 격차가 더 벌어지거나 좁혀질 가능성이 있다.

### 논문 수치와의 비교
| 항목 | 논문 (45 에폭) | 본 실험 (8 에폭, 시드 1개) |
|---|---|---|
| 테스트 정확도 | 94.00% | 87.58% |
| F1-score | 93.99% | 87.49% |
| 5-fold 평균 | 91.66 ± 2.78% | 72.93 ± 3.06% (3 에폭) |
| 최대 오류 쌍 | D → C 13건 | D → C 25건 |
| 파라미터 수 (DenseNet161) | 26,483,045 | 26,483,045 (동일) |

차이가 난 이유: 가장 큰 원인은 **에폭 수**다. 본 실험은 시간 제약으로 45 에폭의 약 18%(8 에폭)만 학습했고, 손실이 아직 수렴하지 않은 상태에서 평가했다(학습 로그상 loss가 8에폭까지 계속 감소 중). 5-fold는 폴드당 단 3 에폭만 학습해 정확도(72.93%)가 본 비교(87.58%)보다도 훨씬 낮은데, 이는 폴드마다 모델을 처음부터 다시 학습하기 때문에 적은 에폭의 영향을 가장 크게 받은 결과다. 그럼에도 표준편차(3.06%)는 논문의 2.78%와 비슷한 수준으로, 분할 방식 자체의 변동성은 에폭 수와 크게 상관없이 작다는 것을 보여준다. 둘째, 논문은 Dropout을 사용했지만 본 실험은 미적용이라 과적합 억제력이 다르다. 셋째, 시드 1개만 사용해 평균의 안정성이 논문(다회 실행 추정)보다 낮다. 최대 오류 쌍(D→C)은 에폭 수와 무관하게 논문과 동일한 방향으로 나타나, 짧은 학습으로도 D-C 간 근활성 패턴이 유사하다는 구조적 특징은 이미 드러난다는 점이 흥미롭다.

## 3. Confusion Matrix 분석

### Model 1 (DenseNet161)
![confusion DenseNet161](results/confusion_densenet161.png)
- 가장 잘 분류된 클래스: A (recall 97.4%, 185/190)
- 가장 많이 오분류된 클래스: D (recall 72.1%, 137/190)
- 주요 오분류 유형: D→C 25건(최대), C→E 21건, D→E 17건, B→E 11건
- 오분류가 발생한 이유에 대한 분석: 논문과 마찬가지로 D와 C 사이의 혼동이 가장 두드러진다. 논문은 피험자 5명의 연령·체형을 의도적으로 비슷하게 구성했다고 밝히는데, 그 결과 D와 C의 파지·회전 시 근활성 패턴이 실제로 유사할 가능성이 높다. 추가로 C→E, D→E로 향하는 오류도 적지 않아, E 클래스 쪽으로 오분류가 약하게 쏠리는 경향도 보인다.

### Model 2 (2D CNN)
![confusion 2D CNN](results/confusion_cnn2d.png)
- 가장 잘 분류된 클래스: A (recall 92.6%, 176/190)
- 가장 많이 오분류된 클래스: B (recall 29.5%, 56/190)
- 주요 오분류 유형: B→E 85건(최대, B 전체의 거의 절반), C→E 36건, B→C 31건
- 오분류가 발생한 이유에 대한 분석: 모델 구조가 2개 합성곱 층뿐이라 표현력이 부족해, B 클래스의 미세한 CWT 패턴을 거의 학습하지 못하고 대부분 E로 찍는 쪽으로 수렴한 것으로 보인다. A를 제외한 모든 클래스에서 E로 향하는 오류가 공통으로 관찰되어, 모델이 과소적합 상태에서 가장 흔한(또는 평균적인) 패턴인 E 쪽으로 예측을 몰아간 것으로 해석된다.

### Model 3 (ResNet18)
![confusion ResNet18](results/confusion_resnet18.png)
- 가장 잘 분류된 클래스: E (recall 96.8%, 184/190)
- 가장 많이 오분류된 클래스: C (recall 65.8%, 125/190)
- 주요 오분류 유형: B→E 52건(최대), C→E 31건, C→B 27건, A→E 27건
- 오분류가 발생한 이유에 대한 분석: E의 recall은 매우 높지만 precision은 58.0%에 그쳐, A·B·C 모두에서 상당수가 E로 잘못 예측됐다(각각 27, 52, 31건). 즉 모델이 E를 "안전한 선택"처럼 과도하게 예측하는 편향을 보이며, 이는 8 에폭만 학습해 결정 경계가 아직 덜 정교하게 잡힌 상태로 보인다. C→B(27건)처럼 DenseNet161에서는 보이지 않던 오류 쌍도 나타나, 베이스라인마다 혼동 패턴이 다르다는 점도 확인된다.

## 4. 최종 결과

- 가장 성능이 좋은 모델: **DenseNet161** (Accuracy 87.58%, F1 87.49%)
- 가장 성능이 낮은 모델: **2D CNN** (Accuracy 60.84%, F1 59.82%)
- 주요 오분류 클래스: 세 모델 모두 **B→E** 또는 **D/C↔C/E** 방향의 오류가 두드러졌다. 특히 B와 C 클래스가 베이스라인에서 공통적으로 약했고, DenseNet161에서는 D-C 혼동이 논문과 동일하게 재현됐다.
- 전체적인 실험 결과 및 느낀 점: 시간 제약으로 원래 45 에폭 계획을 8 에폭(5-fold는 3 에폭)으로 줄였음에도, 모델 간 성능 순서(DenseNet161 > ResNet18 > 2D CNN)와 파라미터 수 순서가 정확히 일치했고, DenseNet161의 최대 오류 쌍(D→C)이 논문과 같은 방향으로 재현된 것이 인상적이었다. 반면 절대 정확도(87.58% vs 논문 94.00%)와 5-fold 평균(72.93% vs 91.66%)은 에폭 수 차이로 상당히 낮게 나와, 딥러닝 모델 비교에서는 "같은 조건"이 성능 순위뿐 아니라 절대 수치의 신뢰성에도 직접 영향을 준다는 점을 체감했다. 시간이 더 있었다면 45 에폭 풀 실행과 시드 3개 평균, Dropout 적용 여부에 따른 비교까지 진행했을 것이다.

### 한계
1. 피험자가 5명뿐이라 결과를 일반화하기 어렵다. 논문도 동일한 한계를 명시하고 있으며, 연령·체형을 의도적으로 비슷하게 구성해 소수 인원 안에서의 판별력만 확인한 실험이다.
2. 모든 데이터가 단일 측정 세션에서 수집되어 날짜·근피로·피부 상태 변화가 반영되지 않았다. 세션이 달라지면 전극 재부착 위치 차이로 성능이 달라질 수 있다.
3. closed-set 전제라 미등록자가 들어오면 반드시 등록자 중 한 명으로 오분류한다. 출입 통제처럼 등록자가 고정된 상황에는 적합하지만, 불특정 다수가 접근하는 환경에는 그대로 적용할 수 없다.
4. 시간 제약으로 45 에폭이 아닌 8 에폭(5-fold는 3 에폭), 시드 1개로만 실행했다. 학습 손실이 아직 수렴하지 않은 상태의 결과이므로, 논문 수치와의 절대 비교보다는 모델 간 상대적 순위와 오류 패턴의 재현 여부를 중심으로 해석해야 한다.
5. 2D CNN 베이스라인은 논문의 2D-CNN(약 494만 파라미터)과 다른, 훨씬 작은 구조(약 2만 파라미터)를 사용해 베이스라인 간 비교가 논문과 1:1로 대응하지는 않는다.
